# ReAct 固定搜索、去摘要实验

这轮只运行新读取器。旧 You.com 在单次公开主页读取探测中返回免费额度耗尽。旧组已按要求暂缓。同题历史结果来自上一轮可改写查询、可见搜索摘要的 ReAct 新读取器。

## 实测结果

20 题均提交了最终答案并完成评分。每题实际调用一次搜索，20 次观察逐字匹配冻结列表。本轮答对第 2、39、40、47、59 题。与上轮相比，第 25、27、42 题由对转错，其余 17 题判分相同。第 42 题上轮读到描写彩旗、旋转木马和追逐场景的公告，本轮未找到对应“幽影小镇”的细节。

| 同 20 题指标 | 上轮动态搜索与摘要 | 本轮固定候选、无摘要 |
|---|---:|---:|
| 正确 | 8/20（40%） | 5/20（25%） |
| 单源 · 多源 | 5/10 · 3/10 | 4/10 · 1/10 |
| 步数 | 97 | 122 |
| 至少读到一张标注页 / 读齐全部标注页 | 10/20 · 8/20 | 10/20 · 5/20 |
| 成功轨迹中的动作 / 正文提取 / 裁判 token | 785,468 · 272,816 · 21,264 | 776,027 · 648,124 · 23,756 |
| 成功轨迹合计 token | 1,079,548 | 1,447,907 |
| 实际记录 token（含中断重试） | 1,156,679 | 1,737,012 |

本轮成功轨迹多用 368,359 token（+34.1%），其中正文提取增加 375,308，动作模型减少 9,441。实际记录合计增加 580,333（+50.2%）。本轮因网络中断续跑 8 道未完成题，其中第 50 题额外重试一次。流水包含中断前服务已返回并记录的 token，无法估计服务未返回用量的请求。

108 个逐 URL 访问结果中有 85 次成功读取，包括 11 次 PDF、12 次历史快照访问（按访问次数，可重复）。第 25 题拿到历史首页仍缺所问期限，第 30 题没有打开两份排在前面的同年指南。取得快照和成功打开 PDF 与最终答案是否完整，需要按题分别核对。

## 条件

- 沿用预定 20 题、Labhuan `claude-sonnet-4-6`、原任务提示、温度 0、24 步、128K 和 legacy-v1 裁判。每题从空历史开始。
- 运行前逐题用原问题做一次公开搜索。每题取返回顺序的前 12 条作候选，过滤可识别的 WebWalkerQA、数据集镜像及相关研究条目，去重后保留前 10 个。共审核 240 条，冻结 194 个题内候选。冻结过程没有用标注 URL、参考答案或上轮轨迹做排序。
- 搜索返回文档编号、站点、类型提示和标题中也出现在问题里的词，省略所有摘要和原始标题。用编号隐藏可能含答案的 URL 路径。每次搜索返回同一列表；模型可以访问任一候选、题目入口，以及阅读器从正文解析出的链接。普通网页或 PDF 正文可以包含答案。
- 读取器支持 HTML、文本层 PDF 和 Wayback 快照；请求历史日期由 agent 决定。本轮启用 CDX 回退，上轮实跑只有 Wayback availability。两轮还存在候选来源、搜索显示内容、工具说明和网页访问范围差异。
- 本机的候选映射和来源审核清单随运行保存在 Git 忽略的 `results/webwalker-frozen20/` 下。候选 SHA-256 记在配置和报告中。分析脚本逐次核对实际送给模型的搜索观察是否等于对应题的冻结列表。

## 本地核对

在 PACE 目录使用原模型配置和已保存的候选。下列命令只读取审核清单、计分结果和用量，以核对候选与统计。运行轨迹保存在 `results/webwalker-frozen20/archive/rep-1/react/`。
