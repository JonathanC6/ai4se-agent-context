# ReAct 自主读取历史网页与 PDF

2026-11-23，在原固定的 10 道单源题和 10 道多源题上各跑一次。每道题从空历史、原网站入口和原问题开始。Labhuan 的动作、网页提取和裁判模型均为 claude-sonnet-4-6，沿用原 ReAct 提示、温度 0、24 步、128K 上下文和 legacy-v1 评分。改动了浏览工具及其说明。参考答案仅供裁判使用。agent 没有收到上轮人工核验的片段、PDF 地址或快照日期。

## 实测

本轮为 **8/20（40.0%）**，单源 5/10，多源 3/10。旧工具在第 50 题耗尽额度，没有判分。下表只比较双方有判分的 19 题，另给出本轮全体数据。

共同题多用 71,700 token（+7.4%）。动作模型多用 103,282 token，网页提取少用 32,425 token；ReAct 会在后续步骤重读累积的搜索结果和网页观察。整批 Labhuan 用量流水为旧 987,454、新 1,156,679 token（+17.1%），包含旧第 50 题的中断调用和新第 42 题第一次网页提取返回无效 JSON 后重跑的用量。公开搜索服务的用量单独于模型流水。

其余 12 道共同题判分保持一致。第 50 题本轮给出多个主题日并倾向 Large Language Model Day，参考为 Online Trust & Safety Day，裁判判错。原先三道可被人工证据修复的题，这次自主解出 1/3。五道题成功提取 8 次 PDF（24、26、30、33、48），这五道的最终判分都没有翻转。全体仅第 24 题显式请求过一次历史快照，成功返回 0 次。按原 URL 匹配衡量的标注页命中率对网页版本不敏感，也会漏掉能作答的等价材料。

## 控制条件及搜索污染

上一轮 You.com 公开入口返回 HTTP 402。本轮对同一道题完全相同的旧查询复用原始搜索响应，其余查询送公开搜索，机械提取标题、URL 和摘要。14 道题使用过新搜索；第 1、15、59 题只复用旧搜索，第 9、39、50 题没有发起搜索。最初第 2、20 题各一次新查询只解析出榜首，后续解析修正。上述两题的实际轨迹保留原样。因此这里只能估算整套浏览工具变化的表现。

共同题从错到对的是第 25、27、42 题，从对到错的是第 20 题。只剔除明确展示本题答案的第 27 题，得分从 6/18 到 7/18。再采用更保守的口径，剔除任一轮搜索结果出现题库或相关研究链接的全部四题（2、15、25、27），两轮均为 5/15。此口径也会移除只是看见论文链接的题；它用于检查结论对剔除规则的敏感性。单次小样本不足以估计全量准确率。

## 运行与核对

在 PACE 目录安装 PDF 依赖。模型使用既有 Labhuan 配置。搜索队列的 pending 返回 agent 的原查询，外部搜索客户端将排序结果经 answer 从标准输入写回。保存的搜索结果可重用；新查询需要运行搜索客户端。HTML 与含文本层的 PDF 支持 offset 分段读取。扫描件尚无 OCR。

```sh
.venv/bin/python -m pip install -r requirements-reader.txt
PYTHONPATH=src .venv/bin/python -m benchmarks.webwalker_archive20 --jobs 5
PYTHONPATH=src .venv/bin/python -m benchmarks.archive20_report
```

本轮使用 Wayback availability 查找临近日期快照。跑后新增的 `--cdx` 开关会在 availability 无结果时检索同年 CDX 索引，选择最接近请求日期的成功抓取，使用独立输出目录；搜索客户端也需传入同一开关。本轮结果没有用这个开关重新评分。
