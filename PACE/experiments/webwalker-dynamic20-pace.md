# 动态搜索下的 PACE 与 ReAct

复用已完成的 20 条 ReAct 判分，只新增同题 PACE 一轮。每组 10 道单源、10 道多源。两个 agent 均从空历史和题目入口出发，自主生成查询、选择页面和提交答案。

## 结果

PACE 为 **7/20（35%）**，ReAct 为 **9/20（45%）**。18 题判分相同，第 15、42 题只在 ReAct 下答对。每组 20 条轨迹均提交最终答案。小样本单轮结果仅描述这批配对题。

| 指标 | ReAct | PACE |
|---|---:|---:|
| 单源 · 多源 | 7/10 · 2/10 | 6/10 · 1/10 |
| 总步数 | 113 | 123 |
| 至少命中一张 · 读齐标注页 | 9/20 · 5/20 | 11/20 · 7/20 |
| 动作模型 token | 898,791 | 674,608 |
| 网页提取 token | 303,609 | 349,986 |
| 历史摘要 token | 0 | 356,070 |
| 裁判 token | 26,195 | 25,020 |
| 总 token | 1,228,595 | 1,405,684 |

PACE 动作模型少用 224,183 token（−24.9%）。计入历史摘要和网页提取，全流程多用 177,089 token（+14.4%）。两组流水与完成轨迹的 token 合计一致。第 32 题首次调用断开，没有返回可记录用量，续跑后完成。PACE 的 58 个不同查询中，3 个与 ReAct 的 45 个查询完全一致，其余 55 个按相同规则重新检索。两组所有搜索观察均已逐条对照缓存核验。

16/20 道题、62/123 个决策步展示过至少一块压缩历史。glimpse 调用为 0，也未发现先压缩、后来再次自动显示为 FULL 的同一历史块。103 个历史块中有 102 个成功生成摘要；第 32 题第一块摘要返回格式错误，该块后续一直全文显示。

## 逐题核验

- **第 15 题，ReAct 对、PACE 错。** ReAct 访问了 Riot 的 5,000 万美元公告。PACE 三条原始观察里均无该数字，终局仅第一块为详细摘要，其余为全文。两组最终取得的证据不同。
- **第 42 题，ReAct 对、PACE 错。** ReAct 从九游 2024 年报道读到彩旗、旋转木马和追逃场景。PACE 读到另一日期的港澳台公告，原始搜索和网页观察也没有出现彩旗或旋转木马。
- **第 25、30 题，两组均错。** 第 25 题 PACE 在 3 步内结束，历史始终全文显示，仍答了其他届次的期限。第 30 题 PACE 走了 12 步，读到了两份指南，最终仍采用了患者报告 11 月 7 日的冲突日期。
- **第 27 题，两组均判错。** PACE 用了 21 步和 251,195 token，列出 2011 年 Lovejoy、Tang 和 2022 年 Shen、Dawande 四人。两个年份均有 POMS 官方材料支持。参考答案每年只列一人。保留统一裁判分数，另记参考答案不全。[2011 年名录](https://pomsmeetings.org/ConfProceedings/060/People/POMS%20Fellows.pdf) · [2022 年大会手册第 45 页](https://pomsmeetings.org/conf-2022/documents/POMS-2022-Program-Book-Version-1.1.pdf)
- **第 32 题，两组均判错。** PACE 点名 The Last Continent 是最相符的影片，并解释向学校传播科研信息的关系；它也强调与第 17 条的关联属于推断。裁判因这个限定判错，适合人工复核。

## 配置与复核

- 两组使用 Labhuan claude-sonnet-4-6 执行动作、正文提取与独立判分，温度 0、legacy-v1、24 步、128K。两组共用公开搜索后端、按原查询字符串保存的缓存、结果排序、标题/摘要/URL、题库过滤和 HTML/PDF/Wayback 读取器。同一查询复用已经过滤的结果，新查询实时搜索，访问网页时正文可能变化。
- PACE 使用本机固定版本的 BGE-M3 INT8 为历史块编码；同一 Sonnet 模型异步生成详细和简短摘要。最近两块保留全文，旧块按语义权重和压力分档。horizon 为 16，阈值为 0.4、0.8、1.5，适应系数 0.5、softmax 温度 0.3，单次 glimpse 可恢复最多 3 块。比较按真实展示给动作模型的档位计算压缩次数；生成过摘要不代表用过摘要。
- 一题一轮，同题不同轨迹，检索缓存内容相同不保证选取相同来源。统计区分最终已判分轨迹和包含中断的请求流水。嵌入在本机执行，其耗时计入求解，不产生 Labhuan token。

在 PACE 目录使用之前动态搜索的 pending/answer 客户端服务新查询。本机已备好编码器和模型配置，以下命令分别续跑、生成配对报告。

```sh
PYTHONPATH=src .venv/bin/python -m benchmarks.webwalker_dynamic20 run --arm pace
PYTHONPATH=src .venv/bin/python -m benchmarks.dynamic20_pace_report
```

## 上下文容量离线核查

以服务端返回的单步 actor 输入计，ReAct 峰值为 39,982 token（第 33 题第 6 步），PACE 峰值为 23,239（第 32 题第 7 步），相当于 128,000 预算的 31.2% 和 18.2%。40 条轨迹全部正常 finish。ReAct 单题最长 8 步，PACE 最长 21 步；二者属于独立生成的轨迹。

另对每条 PACE 轨迹固定已执行动作与工具观察，把当前步之前的所有历史重建为 FULL，保留 PACE 的系统提示、题目与块格式。123 个离线重建输入中，项目计数器 Utf8Counter 的最大估计为 82,534（第 27 题第 21 步），没有触及 128,000。61 个原本已全部显示为 FULL 的步骤，重建值逐项等于原日志估计值。此处为带消息开销的 UTF-8 字节代理值；假设的全量输入没有提交给 Labhuan，也未重跑动作或判分。

PACE 所有历史块在各步的实际展示合计 FULL 190 次、DETAILED 124 次、BRIEF 164 次、PLACEHOLDER 0 次。glimpse 由 agent 显式选择，压力与语义权重调整的是展示档位。第 27 题有 6 步压力达到 1，原因是步数达到本地 horizon 16。论文图 2 的 128K 长程对照来自 GAIA Level 3；论文没有给出 WebWalkerQA 的 glimpse 调用率。[论文 §3.3–3.4、图 2 和附录 D](https://aclanthology.org/2026.acl-long.1252.pdf)
