## 其余题如何解读

全部题的首判、实际提档数和 token 见逐行对照表。四组均正确的题没有观察到准确率增益；四组均错误的题没有被当前策略解决。对相同首判的题未追加匿名复评。

- 第 221 行四组均失分。官网列出了作者回复期间新增的两个章节，但参考答案只概括了新增两节的缘由，原先两题试跑和本次独立运行的评分也有差异。这是人工复核时应保留的参考答案粒度问题。
- 第 369、76 行及新增题中的部分历史奖项、会议记录缺少标注 URL。第 6 行则说明即便 URL 收录，页面年份也可能发生变化。覆盖不足与网页内容迁移都会影响四组共同的绝对准确率。
- 第 22、8、27 行的 D 轨迹实际使用了 supersedes，均未带来正确答案。开启替代字段也会改变动作提示，不能将 C 与 D 的全部得分差解释为旧版本过滤的收益。

## 准确率与开销合起来看

仅加 DAG 后 3 题错转对、3 题对转错，平均步数从 9.38 降至 8.23，总 token 减少 202,114（9.3%）。动作模型累计输入却从 905,420 小幅增至 909,533；节省主要来自摘要与向量调用。B 加 Anchor 后总 token 增加 375,623（19.1%），正确数仍为 13。完整 D 对 A 为 4 题错转对、2 题对转错，双侧精确 McNemar 检验 p=0.688。每题每组一次的结果尚不能建立稳定的准确率优势。
